# Frontend (Next.js)

This directory contains the Atlas DAQ frontend built with Next.js 14 (App Router), React 18, TypeScript, and Tailwind CSS.

## Requirements
- Node.js 20+
- pnpm 9+ (or compatible)

## Environment variables
Create a `.env.local` in this folder (or use the provided `.env.example` at the repo root as reference):

- `NEXT_PUBLIC_API_BASE` — Base URL for REST endpoints (e.g. `http://localhost:5001`).
- `NEXT_PUBLIC_SOCKET_URL` — Socket.IO endpoint (usually same as API, e.g. `http://localhost:5001`).

These are read by `lib/api.ts`.

## Scripts

- Development server:
  ```bash
  pnpm dev
  ```

- Build static export (writes to `frontend/out`):
  ```bash
  pnpm build
  ```
  The project uses `output: 'export'` in `next.config.mjs`, so the `build` step also produces the static site.

- Lint:
  ```bash
  pnpm lint
  ```

## Project structure
- `app/` — App Router entry (`layout.tsx`, `page.tsx`).
- `components/` — UI components and feature modules.
- `hooks/` — Custom hooks.
- `lib/` — API and socket manager.
- `public/` — Static assets.
- `styles/` — Global styles.
- `out/` — Static export generated by the build.

## Notes
- The backend (Flask) serves the static frontend from `../frontend/out` configured in `backend/config.ini`.
- Use `pnpm dev:full` at repo root to run both frontend and backend together.

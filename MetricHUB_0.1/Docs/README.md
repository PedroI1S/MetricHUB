# MetricHUB

MetricHUB is a comprehensive Data Acquisition and Monitoring Platform.

## 🚀 Quick Start

### Prerequisites
1.  **Docker**: Ensure Docker Desktop is installed and running.
2.  **Node.js & pnpm**: Required for the frontend.
3.  **Python 3**: Required for the backend.

### Setup & Run

1.  **Start Database**
    ```bash
    # From the project root (where docker-compose.yml is)
    docker compose up -d
    ```

2.  **Install Dependencies**
    ```bash
    cd MetricHUB_0.1
    pnpm install
    # Python venv is handled by the start script or manually:
    # python3 -m venv .venv && ./.venv/bin/pip install -r requirements.txt
    ```

3.  **Run Application**
    ```bash
    # This builds the frontend and starts the backend
    pnpm dev:full
    ```

4.  **Access**
    - Dashboard: [http://localhost:5001](http://localhost:5001)

## 🗄️ Database Management
Access the database via web interface:
- **URL**: [http://localhost:8080](http://localhost:8080)
- **Select System**: PostgreSQL
- **Server**: `metrichub_postgres` (or `postgres` if that fails)
- **Username**: `metrichub_user`
- **Password**: `metrichub_password`
- **Database**: `metrichub_db`

# Frontend (Next.js)

This directory contains the Atlas DAQ frontend built with Next.js 14 (App Router), React 18, TypeScript, and Tailwind CSS.

## Requirements
- Node.js 20+
- pnpm 9+ (or compatible)

## Environment variables
Create a `.env.local` in this folder (or use the provided `.env.example` at the repo root as reference):

- `NEXT_PUBLIC_API_BASE` — Base URL for REST endpoints (e.g. `http://localhost:5001`).
- `NEXT_PUBLIC_SOCKET_URL` — Socket.IO endpoint (usually same as API, e.g. `http://localhost:5001`).

These are read by `lib/api.ts`.

## Scripts

- Development server:
  ```bash
  pnpm dev
  ```

- Build static export (writes to `frontend/out`):
  ```bash
  pnpm build
  ```
  The project uses `output: 'export'` in `next.config.mjs`, so the `build` step also produces the static site.

- Lint:
  ```bash
  pnpm lint
  ```

## Project structure
- `app/` — App Router entry (`layout.tsx`, `page.tsx`).
- `components/` — UI components and feature modules.
- `hooks/` — Custom hooks.
- `lib/` — API and socket manager.
- `public/` — Static assets.
- `styles/` — Global styles.
- `out/` — Static export generated by the build.

## Notes
- The backend (Flask) serves the static frontend from `../frontend/out` configured in `backend/config.ini`.
- Use `pnpm dev:full` at repo root to run both frontend and backend together.

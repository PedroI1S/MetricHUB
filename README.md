# MetricHUB

**MetricHUB** is a comprehensive Data Acquisition and Monitoring Platform designed for real-time sensor data collection, visualization, and analysis in laboratory and industrial environments.

*   [**API Reference**](https://github.com/PedroI1S/MetricHUB/wiki/API-Reference): Endpoints and Socket.IO events.

## 🚀 Key Features

*   **Real-time Acquisition**: Continuous data collection from multiple 22-channel collectors.
*   **Modern Web Dashboard**: Responsive Next.js frontend with smooth animations.
*   **Robust Backend**: Python Flask server with Socket.IO.
*   **Data Integrity**: SQLite database with normalized schema.
